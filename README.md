# bot_modular-feedback

Публичный трекер обратной связи проекта **bot_modular** (модульный Telegram/Web-бот).

## Статус репозитория

- Исходный код в данном репозитории отсутствует. Разработка ведётся в закрытом Forgejo.
- Назначение репозитория: приём сообщений об ошибках, предложений и вопросов через Issues.
- Официальный сайт проекта: https://euk0r.ru/projects/bot-modular
- Прямая связь с автором: https://t.me/euk0r

## Установка

```sh
curl -fsSL https://euk0r.ru/projects/bot-modular/install/install.sh | bash
```

Подробности (состав установки, обновление модулей через маркет) — на сайте проекта:
https://euk0r.ru/projects/bot-modular

## Как сообщить об ошибке

1. Раздел Issues → New issue. Шаблон: Баг, Идея или Вопрос.
2. Указать модуль и его версию (таблица версий на странице модуля на сайте).
3. Описать шаги воспроизведения, ожидаемый и фактический результат.
4. Логи прилагать текстом, предварительно удалив токены и секреты.
5. Перед отправкой проверить поиском, что такое issue ещё не заведено.
